# Pi Workbench

Переносимая сборка **Pi 1.5.0**: текущий профиль командной строки, 11 зафиксированных npm-плагинов, 228 навыков, 39 команд-шаблонов и локальные исправления. Это снимок установленной рабочей конфигурации, а не незавершённый fork ядра.

Единственное обновление навыка относительно рабочей установки — `pptx`: его старая версия запрещала распространение, поэтому публичная копия содержит полную Apache-2.0 версию из зафиксированной ревизии upstream. Остальные особенности сборки сохранены.

## Что внутри

- Модель по умолчанию: `openai-codex / gpt-5.5`, thinking `xhigh`, fullscreen, тёмная тема.
- CodeMode и поиск инструментов; RTK для сокращения вывода shell-команд.
- Subagents, задачи, supervisor, расписания, GitNexus, Lens, процессы, инспектор, interactive shell, web tools и condense.
- Управление панелями через `/panels`, F6 и Ctrl+Alt+H; исправление stale context в `pi-inspect`.
- 217 сохранённых навыков и ещё 11 из npm-плагинов; Memory Bank, рабочие правила и шаблоны команд.
- MCP Radius с публичным endpoint. Авторизация выполняется пользователем самостоятельно.

## Установка

Нужны Node.js ≥22.19, npm, Git и `patch`. Проверено на macOS. RTK ≥0.23 нужен для расширения RTK; без него расширение отключается. Инструменты отдельных навыков устанавливаются по мере необходимости.

```sh
git clone https://github.com/fockus/pi-workbench.git
cd pi-workbench
sh scripts/install.sh
export PATH="$PWD/scripts:$PATH"
pi
```

В Pi выполните `/login` и подключите собственную учётную запись либо выберите провайдера и настройте собственный ключ. Ключи в репозиторий не добавляйте.

Установщик откажется работать, если `~/.pi/agent` уже существует, и сохранит текущую конфигурацию. Для отдельной установки используйте новый аккаунт ОС или отдельное домашнее окружение. Храните checkout после установки: команда `scripts/pi` использует ядро из его `node_modules`. Добавьте каталог `scripts` в PATH своей оболочки, если хотите запускать эту сборку в новых терминалах.

Версии фиксируются двумя lock-файлами. npm lifecycle scripts отключены; плагины устанавливаются с `--legacy-peer-deps`, как в исходном дереве, чтобы npm не подставлял другую версию Pi. Обновление плагинов может удалить локальные патчи.

## Данные и проверка

В снимке нет файлов авторизации, API-ключей, сессий, переписки, задач, расписаний, памяти проектов, снимков инспектора, доверенных каталогов, кешей, резервных копий или идентификатора устройства. Пустые шаблоны Memory Bank являются частью навыка. Git-история начинается с очищенного снимка.

Перед публикацией: Gitleaks — 0 находок; отдельная проверка на значения из локального файла авторизации — 0 совпадений. Все 1 286 файлов ядра и 1 900 файлов прямых npm-плагинов после патчей совпали с исходной установленной версией. В изолированном HOME загружаются те же 228 навыков, 15 расширений и 39 шаблонов без ошибок расширений. Сохранены 10 предупреждений о формате названий сторонних навыков; сами навыки загружаются.

Проверена настоящая установка в чистый HOME и локальные тесты патчей. Запрос к модели не выполнялся: для него нужны ваши собственные доступы. Проектные настройки и внешние сервисы не входят в снимок.

```sh
python3 -m unittest discover -s tests -p test_install.py
PI_WORKBENCH_INTEGRATION=1 python3 -m unittest discover -s tests -p test_install_integration.py
node --test agent/panel-visibility/tests/installer.test.mjs
node --experimental-vm-modules --test tests/inspect.test.mjs
```

Тесты патчей требуют установленных зависимостей и применённых патчей. SDK-тесты панелей запускайте с отдельным HOME, поскольку сторонние плагины сохраняют состояние в домашнем каталоге.

Источники, версии и хеши навыков: [manifest.json](manifest.json). У компонентов разные лицензии; атрибуция и условия — [THIRD_PARTY.md](THIRD_PARTY.md).
