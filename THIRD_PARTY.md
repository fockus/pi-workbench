The snapshot was packaged on 2026-11-25. Packaging changes include materializing links, removing runtime data and backups, and replacing personal home-directory examples. Educational fake-token examples were normalized during the privacy audit. Source instructions remain otherwise as installed unless the release manifest explicitly records an update.

`Not verified` means no redistribution permission has been established by this audit; it is not an open-source license. A current upstream license is not substituted for a historical version with different terms.
